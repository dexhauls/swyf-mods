Malwarebits · Troubleshooting

Problems found: 6. All of them can be fixed.

The hub didn't find the game

Click Choose game folder. Steam tells you where the game is: right-click the game → Manage → Browse local files. It's the folder with Scam With Your Friends.exe.

The game stutters or the PC runs out of memory

With Better Czech Speech, switch to the turbo model. The large model takes about 4 GB of graphics memory, and the game with it around 8.5 GB of RAM.

Close programs that record the game in the background, such as SteelSeries GG Moments. They can eat tens of GB of memory.

I want to switch Czech speech to turbo

Double-click CzechSpeech-1.0.3.swyfmod again, switch on the turbo model and install. Then in BepInEx\config\dex.swyf.czechspeech.cfg in the game folder change Model = large-v3 to Model = turbo. It takes effect after restarting the game.

Does it work in a friend's lobby?

Better Czech Speech works in any lobby. The new gestures need the mod on the host too.

The microphone doesn't transcribe anything

Check the game's audio settings for the right microphone. Better Czech Speech uses the same input as the game, it just transcribes it better.

I want to turn a mod off or remove it

Open SWYF Mod Hub (it's in the Start menu). Each mod has a switch to turn it off and a bin to remove it. Uninstall all puts the game back the way it was.
